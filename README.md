# 内燃机分布式能源负荷分析计算程序

一个基于 VB.NET 开发的 Windows 应用程序，专门用于**内燃机分布式能源系统**的冷热负荷分析计算。该程序通过 COM Interop 与 Microsoft Excel 深度集成，从 Excel 工作簿中读取设备选型、负荷需求、运行工况等输入数据，执行复杂的多设备联合负荷分配与全局寻优计算，并将设备负荷率、天然气耗量、耗电量等计算结果写回 Excel 生成完整的负荷分析报表体系。

## 核心计算模块详解

### 1. 主计算程序.vb（~700行）

**模块名:** `主计算程序`

这是整个程序的核心调度模块，包含计算主程序和负荷分析计算程序两个核心入口。

#### 函数列表

| 函数名 | 类型 | 参数 | 返回值 | 功能说明 |
|--------|------|------|--------|----------|
| `计算主程序` | Sub | `ExcelApp, precision, GDDJ_GF1~QT2, TRQDJ, JSMS, TS_XZ` | 无 | **总入口**。验证Excel版本→清空数据→统计工况数→判断设备选择→读取数据→遍历所有工况进行负荷分析→负荷率修正→修正系数计算→最终正确性判断 |
| `负荷分析计算程序` | Sub | `ExcelApp, b, FHTJJD, JSBC, D_price~TRQ_price, calculation_mode, TJGRFHBL, HSGRGLBL` | 无 | **单工况负荷分析核心**。根据内燃机是否可以向外供电、供电量是否有上限、余热是否可以浪费等条件组合，分发到不同的计算路径 |
| `蓄能分配计算主程序` | Sub | `ExcelApp, XLGL_PJ, XLGL_MAX, XLJS_MS, XRGL_PJ, XRGL_MAX, XRJS_MS, QT1_SJD, QT2_SJD` | 无 | **蓄能分配核心**。根据日期序号分组，计算每个日期段的蓄冷/蓄热功率分配和高峰段供冷/供热功率 |

**调用的外部模块:** `读取基础数据`, `辅助程序`, `制冷季常规模式计算`, `采暖季常规模式计算`, `制冷季内燃机及其余热利用计算`, `采暖季内燃机及其余热利用计算`, `制冷季全局寻优计算`, `采暖季全局寻优计算`, `计算前后正确性判断和系数计算`, `梯级供热和混水供热计算`

### 2. 制冷季常规模式计算.vb（~1160行）

**模块名:** `制冷季常规模式计算`

计算制冷季（夏季）各空调设备在常规计算模式下的负荷率，支持7种制冷设备、6个优先顺序。

#### 函数列表

| 函数名 | 类型 | 参数 | 功能说明 |
|--------|------|------|----------|
| `常规计算模式制冷和蓄冷计算` | Sub | `ExcelApp, b, FHTJJD, JSBC, XHLZL, HSLFH, calculation_mode` | **制冷常规模式主入口**。依次调用设备六种顺序制冷和蓄能装置蓄冷计算 |
| `设备六种顺序制冷常规模式计算` | Sub | `ExcelApp, b, FHTJJD, JSBC, XHLZL, HSLFH, calculation_mode` | **六顺序制冷核心**。按用户设定的6个优先顺序，依次对每种设备调用对应的常规模式供冷计算函数 |
| `离心式冷水机常规模式供冷计算` | Sub | `ExcelApp, b, FHTJJD, JSBC, JDZLL` | 离心式冷水机(1)(2)的二分法负荷率计算，先确定负荷率上下限再精细调整 |
| `风冷螺杆式热泵常规模式供冷计算` | Sub | 同上 | 风冷螺杆机(1)(2)的负荷率计算 |
| `空气源热泵常规模式供冷计算` | Sub | 同上 | 空气源热泵(1)(2)的负荷率计算 |
| `水_地源热泵常规模式供冷计算` | Sub | 同上 | 水(地)源热泵(1)(2)的负荷率计算 |
| `水冷螺杆机常规模式供冷计算` | Sub | 同上 | 水冷螺杆机(1)(2)的负荷率计算 |
| `离心式热泵常规模式供冷计算` | Sub | 同上 | 离心式热泵(1)(2)的负荷率计算 |
| `直燃型溴化锂常规模式供冷计算` | Sub | 同上 | 直燃型溴化锂(1)(2)的负荷率计算 |
| `蓄能装置蓄冷工况常规模式计算` | Sub | `ExcelApp, b, FHTJJD, calculation_mode` | 蓄能装置蓄冷工况的计算，根据6个顺序依次调用各设备的蓄冷计算 |
| `离心式冷水机常规模式蓄冷计算` | Sub | `ExcelApp, b, FHTJJD, NUM1, NUM2` | 离心式冷水机的蓄冷启动数量计算 |
| `风冷螺杆式热泵常规模式蓄冷计算` | Sub | 同上 | 风冷螺杆机的蓄冷启动数量计算 |
| `空气源热泵常规模式蓄冷计算` | Sub | 同上 | 空气源热泵的蓄冷启动数量计算 |
| `水_地源热泵常规模式蓄冷计算` | Sub | 同上 | 水(地)源热泵的蓄冷启动数量计算 |
| `水冷螺杆机常规模式蓄冷计算` | Sub | 同上 | 水冷螺杆机的蓄冷启动数量计算 |
| `离心式热泵常规模式蓄冷计算` | Sub | 同上 | 离心式热泵的蓄冷启动数量计算 |

**计算算法:** 所有设备供冷/供热计算均采用**二分法+精细步进**策略：先用0.5/0.25/0.75三个点确定负荷率上下限范围，再以用户设定的精度（FHTJJD）步进搜索满足负荷需求的最低负荷率。

### 4. 制冷季内燃机及其余热利用计算.vb（~1260行）

**模块名:** `制冷季内燃机及其余热利用计算`

处理内燃机在制冷季的各种运行场景，是整个制冷季计算的核心控制模块。

#### 函数列表

| 函数名 | 类型 | 参数 | 功能说明 |
|--------|------|------|----------|
| `内燃机可以向外供电时制冷设备运行计算` | Sub | `ExcelApp, b, FHTJJD, JSBC, HSLFH, D_price, TRQ_price, calculation_mode` | **内燃机可以向外供电的制冷主入口**。将用户输入的内燃机负荷率带入计算，调用溴化锂余热利用系统计算，然后调用常规模式和全局寻优模式进行设备计算 |
| `内燃机不可以向外供电时制冷设备运行计算` | Sub | 同上 | **内燃机不可以向外供电的制冷主入口**。内燃机负荷率从1递减搜索，优先降低内燃机(2)负荷率，当(2)降至0时再降低(1)的负荷率。需要同时满足向外供电量≤0和制冷负荷需求满足两个条件 |
| `内燃机不可以向外供电时制冷计算修正` | Sub | 同上 | 当二分法找到的负荷率不完全满足条件时，进行精细修正计算 |

## 制冷季计算模块详解

### 制冷季常规模式计算.vb

该模块实现了制冷季设备供冷的**顺序优先分配算法**：

1. 优先使用内燃机余热产生的溴化锂制冷量和蓄能装置供冷量
2. 然后按用户设定的6个优先顺序，依次启动各空调设备
3. 每种设备支持(1)和(2)两个型号，(1)满载后才启动(2)
4. 所有设备的负荷率均采用**二分法+步进精调**算法确定

### 制冷季内燃机及其余热利用计算.vb

该模块处理内燃机在制冷季的3种运行场景：

| 场景 | 条件 | 计算策略 |
|------|------|----------|
| 可以向外供电 | Cells(27,9)="Y" | 用户手动输入内燃机负荷率，程序按该负荷率计算 |
| 不可向外供电且供电量无上限 | Cells(28,9)="N" | 内燃机负荷率从1递减，直到向外供电量≤0 |
| 不可向外供电且供电量有上限 | Cells(28,9)="Y" | 结合供电量上限和冷负荷需求双重约束搜索 |

每种场景又分为：
- **仅制冷**（蓄冷量=0，冷负荷>0）
- **制冷+蓄冷**（蓄冷量>0，冷负荷≥0）
- **余热可浪费**（溴化锂多余热量可浪费）
- **余热不可浪费**（溴化锂制冷量必须刚好满足需求）

## 蓄能分配计算详解

`蓄能分配计算主程序`是处理蓄冷蓄热的独立功能模块，其核心逻辑：

1. **按日期序号分组**: 将工况按日期序号分组，同一日期序号的工况共享蓄能分配
2. **确定最大蓄冷/蓄热功率**: 根据用户选择的模式（固定最大值/自适应装机容量）
3. **分配蓄冷功率**: 在谷电/其它时段分配蓄冷功率，优先装机容量大的工况
4. **分配高峰段供冷**: 在高峰段平均分配蓄冷装置的供冷功率
5. **分配峰段/平段供冷**: 剩余蓄冷量继续分配到峰段和平段
6. **反向修正**: 如果蓄冷和供冷能量偏差>4%，反向修正蓄冷功率
7. **验算**: 验证蓄冷总量和供冷总量误差不超过5%

## 安全与保护机制

### 1. 自保护

- 屏蔽 `Ctrl+Break` 中断键
- 验证白名单文件 `C:\Windows\WhiteList_CJC.txt`
- 验证本机 MAC 地址
- 验证网络时间（通过百度.com）或本地时间
- 验证失败时自动保存并关闭 Excel

### 2. 计算结果验证

- 设备负荷率正确性检查（设备运行信息汇总工作表）
- 天然气消耗量修正系数验证
- 耗电量修正系数验证
- 蓄冷/蓄冷总量平衡验算（误差<5%）

### 3. 工作表保护

- 计算前解锁，计算后自动锁定
- 内部计算工作表设为"彻底隐藏"

- Windows 操作系统
- COM Interop 引用: Microsoft.Office.Interop.Excel, WbemScripting

### 构建步骤

1. 打开 `内燃机分布式能源负荷分析计算程序.sln`
2. 选择构建配置: Debug 或 Release
3. 生成解决方案

### 部署步骤

```cmd
regasm 内燃机分布式能源负荷分析计算程序.dll /codebase /tlb
```

---

## 注意事项

1. **计算中断**: 计算过程中 `Ctrl+Break` 已被屏蔽，请勿强制关闭
2. **表格保护**: 计算完成后表格自动锁定，需修改请进入维护模式
3. **工况数量**: 最多支持 200 种不同工况（行8-207）
4. **负荷调节精度**: 必需能被25整除（如0.1/0.25/0.5/1等）
5. **同工况限制**: 同一个工况不可以同时计算供冷和供热，必需分开计算
6. **文件备份**: 建议在运行计算前备份 Excel 文件
7. **全局寻优速度**: 全局寻优模式计算较慢，建议先用常规模式验证后再切换
8. **计算错误自动重试**: 程序会自动降低精度重算出错工况，并提示用户
